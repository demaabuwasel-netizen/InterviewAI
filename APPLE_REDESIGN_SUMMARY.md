## Key Changes

### 1. **Typography → Apple San Francisco**
```
BEFORE: Inter 700 (bold, heavy)
AFTER:  SF Pro Display 400-600 (thin, elegant)
```
- Uses Apple's system fonts
- Lighter weights (more elegant)
- Standard letter-spacing: -0.02em
- Result: Premium, refined feel

### 2. **Colors → Apple Blue**
```
BEFORE: Vibrant cyan #06b6d4
AFTER:  Apple blue #007aff
Text:   Apple black #1d1d1d
Muted:  Apple gray #86868b
```
- Single accent color (not rainbow)
- Deep blacks and refined grays
- Clean, premium palette
- Result: Understated elegance

### 3. **Cards → Floating & Spacious**
```
BEFORE: border-radius: 1rem, padding: 1.5rem
AFTER:  border-radius: 20px, padding: 2.5rem
```
- More organic rounded corners
- Generous internal padding
- Soft subtle shadows
- Result: Weightless, premium feel

### 4. **Buttons → Simple & Confident**
```
BEFORE: Cyan gradient, sharp edges
AFTER:  Apple blue solid, 12px rounded
```
- No gradients
- Clean, simple, confident
- Smooth blue with soft shadow
- Result: Apple App Store aesthetic

### 5. **Spacing → Extreme Whitespace**
```
BEFORE: 1.5rem gaps
AFTER:  3rem gaps (52px)
```
- Breathing room everywhere
- Cards more separated
- Nothing feels crowded
- Result: Calm, composed feeling

### 6. **Navigation → Frosted Glass**
```
BEFORE: Flat white bar
AFTER:  Blur effect + transparency
```
- Modern frosted glass look
- Minimal visual weight
- Elegant, premium
- Result: Feels like Apple's design

### 7. **Shadows → Almost Invisible**
```
BEFORE: Multiple layer shadows
AFTER:  Single soft shadow
```
- 0 4px 6px rgba(0,0,0,.07)
- Barely perceptible
- Elements feel weightless
- Result: Minimalist elegance

### 8. **Icons → Thinner & Minimal**
```
BEFORE: Standard weight icons
AFTER:  Thin, refined icons
```
- Using Lucide icons (already minimal)
- Consistent sizing
- Premium appearance
- Result: Coherent Apple aesthetic

## Color System

```
PRIMARY:        #007aff (Apple Blue - used sparingly)
TEXT:           #1d1d1d (Apple's deep black)
MUTED:          #86868b (Apple's signature gray)
BORDERS:        #e5e5ea (Almost invisible)
BACKGROUNDS:    #ffffff (Pure white)
SUCCESS:        #34c759 (Apple Green)
WARNING:        #ff9500 (Apple Orange)
```

**Strategy**: One accent color. Everything else neutral. Maximum elegance.

---

## Typography Hierarchy

```
Hero Title:     3.5rem, 700 weight (commanding but refined)
Section:        1.75rem, 600 weight (elegant, clear)
Card Title:     1.5rem, 600 weight (prominent)
Body:           1.1rem, 400 weight (readable, light)
Label:          1rem, 500 weight (minimal)
Caption:        0.95rem, 400 weight (delicate)
```

**Characteristic**: Uses LIGHTER weights, not heavier. Apple's signature approach.

---

## Spacing & Layout

```
Hero to Card:       3rem gap (52px)
Card to Card:       3rem gap (52px)
Card Padding:       2.5rem (40px all sides)
Internal Gaps:      1.5-2rem (24-32px)
Navigation Padding: 32px left/right
Button Padding:     0.875rem 2rem (horizontal emphasis)
```

**Strategy**: Extreme whitespace. Everything feels spacious and premium.

---

## Transitions & Motion

All interactions use Apple's signature easing:
```css
transition: 0.25s cubic-bezier(0.4, 0, 0.2, 1);
```

**Characteristic**: Smooth, predictable, premium feel. No jarring animations.

---

## Border Radius Consistency

```
Cards:          20px (organic, floating)
Buttons:        12px (softer than before)
Inputs:         10px (refined)
Wizard Options: 16px (balanced)
```

**Characteristic**: Slightly rounded, never sharp, feels organic.

---

## Shadow System

```
Light:   0 4px 6px rgba(0,0,0,.07), 0 1px 3px rgba(0,0,0,.06)
Medium:  0 8px 16px rgba(0,0,0,.1), 0 2px 8px rgba(0,0,0,.08)
Dark:    0 12px 16px rgba(0,0,0,.1), 0 2px 8px rgba(0,0,0,.08)
```

**Characteristic**: Soft, subtle, barely noticeable. Weightless appearance.
