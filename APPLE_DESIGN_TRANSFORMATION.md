I've completely redesigned PrepWise to match **Apple's signature design language**. Every element now embodies Apple's approach to product design.

## Typography: Apple San Francisco

### Font Stack
```css
font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 
             'Segoe UI', 'Helvetica Neue', sans-serif;
```

**What This Means**:
- Uses Apple's SF Pro Display font on Apple devices
- Falls back to system fonts on other devices
- Ensures native Apple aesthetic everywhere

### Typography Scale (Apple-Inspired)
```
Page Title:      3.5rem, weight 700 (bold, commanding)
Section Title:   1.75rem, weight 600 (refined, clear)
Card Title:      1.5rem, weight 600 (elegant)
Body Text:       1.1rem, weight 400 (readable)
Label:           1rem, weight 500 (subtle)
Caption:         0.95rem, weight 400 (minimal)
```

**Apple Characteristic**: Uses **lighter weight fonts** (400-600) instead of heavy bold (700-900)

## Cards & Spacing

### Card Design
```css
Border radius:   20px (more organic, less geometric)
Padding:         2.5rem (40px - very generous, Apple-like)
Border:          1px solid #f5f5f7 (almost invisible)
Shadow:          0 4px 6px rgba(0,0,0,.07), 0 1px 3px rgba(0,0,0,.06)
                 (soft, subtle, almost not there)
Transition:      0.25s cubic-bezier(0.4, 0, 0.2, 1)
                 (Apple's signature easing curve)
```

**Apple Characteristic**: Cards feel **almost weightless**, like they're floating above the page.

### Spacing Strategy
```
Hero Section:    Gap 3rem (52px)
Between Cards:   Gap 3rem (48px)
Card Padding:    2.5rem (40px)
Internal Gaps:   1.5-2rem (24-32px)
```

**Apple Characteristic**: **Extreme whitespace** - breathing room everywhere.

## Buttons

**Apple Characteristic**: Clean, simple, confident. No gradients, no tricks.

**Apple Characteristic**: Minimal, refined, lets the primary button lead.

## Overall Design Principles Applied

### 1. **Extreme Minimalism**
- Only essential elements
- No decorative effects
- No gradients
- Maximum whitespace

### 2. **Refined Elegance**
- Light font weights (not bold)
- Generous spacing
- Subtle shadows
- Premium materials feel

### 3. **Single Accent Color**
- #007aff Blue used strategically
- Not overused
- Draws attention where needed
- Creates visual hierarchy

### 4. **Organic Rounded Corners**
- 12-20px radius
- Softer, more human
- Never sharp edges
- Feels premium and approachable

### 5. **Premium Typography**
- Apple's SF Pro Display font
- Letter spacing -0.02em (Apple standard)
- Light-to-medium weights
- Clear visual hierarchy

### 6. **Breathing Room**
- 3rem gaps between sections
- 2.5rem padding in cards
- Never feels crowded
- Feels calm and composed

### 7. **Subtle Interactions**
- 0.25s transitions
- Cubic-bezier easing (Apple's curve)
- No sudden changes
- Smooth, natural motion

### 8. **Deep Blacks & Clean Grays**
- Text: #1d1d1d (Apple's deep black)
- Muted: #86868b (Apple's signature gray)
- Borders: #f5f5f7 (almost invisible)
- Creates perfect contrast
